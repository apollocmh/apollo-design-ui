# ADR 0005：Apollo 独立契约与质量体系

- 状态：已接受
- 日期：2026-10-23
- 依据：用户明确要求 Apollo Design 独立发展

## 决策

Apollo 的公开 API、用户场景与组件契约是功能依据。Vue Native、TypeScript、静态 CSS + CSS 变量、无障碍、组件一致性和质量门禁保持。取消上游版本绑定、组件/API/Token 同构、强制任务波次和 React 像素验收。

根目录各领域规范按职责作为 Source of Truth，Registry 只记录事实与证据。正常 Registry 生成从 Apollo 自有记录计算派生图，不再读取 antd 清单；参考版本与旧对照状态单独保留。默认视觉入口比较 Apollo 审查后的基线，上游对照保持显式可选。

## 对旧决策的影响

- 0001：保留静态样式与变量，取消变量必须同构以及依靠上游方向证明方案的要求。
- 0002：共享消费者数是信号；边界同时取决于职责、维护和发布成本，不再是唯一判据。
- 0003：复用/生成/内部实现/独立包/移除仍是工具，来源生态不代替许可与技术评估。
- 0004：保持当前零上游运行时依赖，不要求为独立化继续重复造纯算法；未来引入依赖须独立决策与产物验证。

## 兼容与证据

不删除或重命名公共 API，不复制 React PNG 冒充 Apollo 基线，不清空已知缺陷和历史状态。保留来源许可、Oracle、审计与回归。新视觉验收逐步完成，缺失明确报告；旧 completed 不是新的验收证明。
