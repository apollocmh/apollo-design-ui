# ADR 0007：Vue 公共用法优先于 React 回调与 DOM 形态

- 状态：已接受
- 日期：2026-10-24
- 依据：用户明确要求「凡为了保留 React 回调/DOM 形态而牺牲 Vue 公共用法的地方，不做兼容，直接修正」。
- 对应台账：D01 / D02 / D03、F09 / F11，及后续复现的同类问题。

## 决策

当前未发布开发阶段，不以保留 React 回调载荷、render prop、位置参数插槽或 DOM 同构为理由牺牲 Vue 模板、作用域插槽、响应性、原生事件、焦点、控件状态与无障碍。存在这类冲突时直接修正 Vue 公共契约，无兼容层、无弃用期，无需逐项重复申请批准。

内容使用原生/作用域插槽；作用域模板需要的多个值以具名对象提供。原生事件名使用 DOM 事件对象，状态变化使用 change 与既有 update/v-model 通道；不把 React 的 `(value,event)` 载荷藏在原生 click 等事件名下。Switch 的 D02 按此方向直接整改，具体键盘与点击行为由独立迁移记录和回归落实，不能把裁决记录当作实现完成。

DOM 结构由 Vue 公共用法、语义、样式与可维护性决定。需要修正时不维持导致重挂载/状态丢失或无障碍错误的旧树形态。React DOM 基线是有日期的参考证据；若与已裁决 Vue 契约冲突，按契约修正测试并补等价/替代覆盖，禁止删断言或放宽阈值来获取绿灯。

业务/算法/取消/异步回调、数据配置、VNode 数据、内部实现字段不因名称像 React 而删除。静态 CSS、严格类型、原生可访问性、已有合理语义样式接口与经用户验收的动效继续保持；不为风格统一夹带重命名、视觉改版或无关 API 清理。

## 实施与证据

逐组件先复现，再同步运行时、公开类型、调用者、双语文档、迁移记录、测试和 Registry 证据；主题分阶段提交。ADR 0006 的内容渲染函数直接迁移是本决定的子集。除本范围之外的兼容政策仍适用，正式发布后的迁移策略按届时政策执行。
