# v0.1.8 发布收口

当前阶段：准备规范环境的视觉候选，尚未完成本版本完整验收，尚未创建或部署 `v0.1.8`。

## 范围与验收

- 根目录及全部 16 个工作区包版本均为 `0.1.8`；发布前确认标签未占用，保留既有 `v0.1.7` 及其他标签。
- 像素捕获统一为 macOS 15.7.9 / 24G830 x64、官方 Chrome for Testing 150.0.7871.125、中文区域及叠加滚动条；实际原生字体度量必须匹配。标准见 [视觉说明](../../tests/visual/README.md)。
- 同一份 SDK 和视觉 fixture 生成完整 1875 场景候选，复用原比较器判断。旧图通过则保留；失败项检查实际截图与关键状态，正确后才接受精确场景，不自动接受整批候选。
- 基线收口后固定一个干净源码提交，执行 `verify-full` 的全部九维、L7/B6、类型、覆盖率、真实 tarball 消费和 Docs 检查。视觉按组件分五路，最终核对完整场景集合；不能用局部通过代替完整验收。
- 完整验收通过后创建指向该冻结提交的注解标签 `v0.1.8` 并推送。标签 CI 仅可复用同一 SHA 已完成的 GitHub Actions 完整验收成功结果；无该证据时仍执行完整门禁。部署从版本标签构建，单独验证 Docs。
- 部署完成后，用真实浏览器检查线上版本、三个主题预设及明暗/系统切换、刷新/路由/iframe 状态保持，以及 Tag 亮暗、间距、窄屏和键盘交互，保留实际页面诊断。
- [ROADMAP](../../ROADMAP.md) 移出已修复数值 zIndex 待办，链接主题、按需引入、Header 与 Tag 的已有交付。支持限制和仍待核实事项继续保留。
