[完整验收 41387164563](https://github.com/apollocmh/apollo-design-ui/actions/runs/41387164563)实际执行冻结提交 `23e20ba603e1dff39af053467aba9ea4ee086507`，结果失败。Registry、格式、L7/B6 构建门禁、发布产物 zIndex 浏览器检查、源码严格类型、公开类型和 tooling 均通过；覆盖率运行中 797 个文件有 1 个失败，17446 条用例中 17445 条通过。后续消费者、正式视觉与 Docs 检查未执行，不能将其记作通过。
