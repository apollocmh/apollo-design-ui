# 组件变更检查清单

规范以根目录 AGENTS / COMPONENT-RULES / TESTING / WORKFLOW 为准。

- [ ] 明确真实场景、公开契约、已知问题和调用者。
- [ ] 缺陷有可失败复现，新 API 有类型与兼容设计。
- [ ] 验证动态 props、slots、attrs、事件、受控状态与卸载。
- [ ] 检查主题、键盘、焦点、ARIA 和适用 SSR 场景。
- [ ] 更新 API、Demo 和受影响 Registry 状态。
- [ ] 运行局部及适用项目检查，记录结果、限制与剩余问题。
- [ ] 视觉改变审阅 Apollo 候选；不拿上游一致替代用户体验判断。
