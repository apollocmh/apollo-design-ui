# 受控状态的 Vue 契约

2026-10-30 起，`useControlledValue` 保留现有参数和返回签名，直接修正开发期内部状态行为：

- `getValue()` 返回 `undefined` 表示非受控；初始受控值优先于默认值。
- 受控更新只通过 `onChange` 提议，父级拒绝的请求不写入本地状态。
- 撤销受控保留最后一次实际接收的值；不重置成 `undefined`，也不泄漏被拒绝的提议。
- 函数式更新读取当前公开值；连续被拒绝的请求不会累积隐藏状态。

因此 `value=3` 时连续提议 `v => v + 1` 都得到 `4`；父级接受 `5` 后撤控保留 `5`。
调用方若需要清空，应先传入其公开契约支持的空值，再撤销受控。
不提供旧 rc 重置语义的兼容选项；原有非受控更新和生命周期释放契约保留。
