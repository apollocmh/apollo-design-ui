# Masonry 首屏与 SSR 行为修正

2026-10-24，按 ADR0007 直接移除为复制 React useEffect 而引入的空首屏延迟。初始 items 和 #item 在服务端输出；数据替换同步进入当前渲染。无兼容层、无弃用期，公共 props/slots 类型不变。

测量前使用 CSS Grid 正常流，按当前列数和间距逐行显示，容器保持自然高度；测量后切换为既有最短列算法与绝对定位。服务端不猜测真实高度或最终落列，#item 的 column 在测量前仍是暂定值 0。空列表保持高度 0。调用方显式 root 样式仍覆盖默认值。

水合直接复用服务端条目与输入节点，测量与入场动画继续运行；移除槽、重排和图片重测量规则保持。对首屏内容有依赖的消费者现在可直接读到条目，不应再等待人为的一拍延迟。

参考 React SSR 的空容器快照仅保留为有日期证据；已有同步客户端入场前根投影测试仍执行，另对相同20场景添加真实SSR内容、类名、间距、样式与网格断言。未改参考基线或降低阈值。
