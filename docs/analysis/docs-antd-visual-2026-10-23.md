## 实现约束

1. 保留 Apollo 品牌、Vue-native API、72 个 UI 组件和独立图标资源口径。
2. 不复制 Ant Design 代码或卡片图片；以本站 Token 和 HTML/CSS 绘制组件预览。
3. 站点外壳、文字、目录与卡片统一视觉参数，保持组件 Demo 样式隔离。
4. Overview 独立 Vue 页面：完整组件清单、名称搜索、分类计数、可识别的代码预览。
5. Icon 独立 Vue 页面：完整 848 项数据集、窗口滚动虚拟行、响应式列数、风格与搜索、
   按需图标 import、复制、键盘定位。没有分页或“加载更多”。
6. SSR 初始结构确定；只在 mounted 后读取窗口、ResizeObserver 与剪贴板。
