本页目录

用于跳转到页面指定位置。

何时使用 ​

  • 需要展示当前页面结构（目录），并支持点击跳转到对应位置。
  • 需要滚动时自动高亮当前所在的锚点。

代码演示 ​

basic：最简单的用法。

customize-highlight：自定义锚点高亮（getCurrentAnchor 只改高亮，onChange 收到的仍是原始 link）。

horizontal：横向 Anchor。

onChange：监听锚点链接改变。

onClick：点击锚点不记录历史（回调里 preventDefault() 可以进一步阻止组件接管 history）。

replace：替换浏览器历史记录中的路径，后退按钮将返回到上一页而不是上一个锚点。

target-offset-per-link：为每条链接单独设置 targetOffset（优先级高于全局的 targetOffset）。

target-offset：锚点目标滚动到屏幕正中间（targetOffset 优先于 offsetTop）。

设计说明 ​

  • 当前锚点的判据：逐链接用 /#([^\t\r\n\f\v]+)$/ 抓 id ⇒ document.getElementById ⇒ getOffsetTop(target, container) ⇒ 保留 top <= (单条 targetOffset ?? 全局 offsetTop) + bounds 的 ⇒ 取其中 top 最大的那个。一个都没有 ⇒ 空串（无高亮）。
  • getOffsetTop 的三条分支：getClientRects() 为空 ⇒ 0；宽高非 0 时按容器基准； 否则直接 rect.top。
  • 滚动监听的依赖是 JSON.stringify(links)，且不含 getContainer —— 容器 prop 变了不会重挂（上游如此，本仓照抄）。
  • 动画期间不抢高亮：handleScroll 在滚动动画进行中直接 return； 再次点击同一个链接时也不重复发 onChange。
  • AnchorLink 的类名前缀取自 ConfigProvider 的根前缀，与 Anchor 的 prefixCls prop 无关 （上游如此）。
  • 零 ARIA：语义完全由原生 <a href> 承担，组件不叠 role / aria-current。 这是上游的有意设计，已由 L5 钉住。
  • 本组件没有 ref / expose（上游是 React.FC，无 forwardRef）。
