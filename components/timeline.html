本页目录

垂直展示的时间流信息。

何时使用 ​

  • 当有一系列信息需按时间排列时；
  • 需要给一个时间序列加上状态与描述时。

⚠️ 本组件在 antd 6.6.4 里没有自己的 DOM —— 它是 Steps 的薄壳： 渲染成 <ol> + <li>（列表语义由原生元素承担），外观由「Steps 的 DOM + Timeline 自己的样式覆盖」共同决定。这也是为什么它支持 variant 等 Steps 的 props。

代码演示 ​

alternate：mode="alternate" 让内容左右交替（按项序号奇偶）。

basic：基础的时间轴 —— 只给 content（无 title ⇒ 纵向不交错）。

custom：icon 自定义节点；自定义 fontSize 时需要自己给背景色（否则连线会透出来）。

end：mode="end" 把节点靠右；icon + color 可以自定义某一项的节点。

horizontal-debug：水平 + 长文本：用 styles.item 画一个 1px 的调试描边，看三种 mode 的排布。

horizontal：orientation="horizontal" 是另一套绝对定位布局（mode 的三种取值各有形态）。

pending-legacy：⚠️ 已废弃的 pending / pendingDot —— 现在请直接在 items 里加一项。

pending：reverse 反转项顺序（⚠️ 连线的状态也随之改跟当前项）；loading: true 的项是「进行中」。

semantic：项级语义化槽（styles.root / rail / content）—— 注意它在 items[i].styles 上，不是根上的。

style-class：styles 支持函数形态（按 info.props 动态返回）；classNames.root 加自定义类。

title-span：titleSpan 控制标题栏的占比：数字按 24 栅格、字符串按 CSS 长度。

title：带 title 的项 ⇒ 纵向时自动进入交错布局（layoutAlternate 的第二条判据）。

variant：variant="filled" 与默认的 "outlined" 是两种视觉变体（透传给内部的 Steps）。

Theme ​

Component Token（6 个） ​

token说明默认值
tailColor轨迹颜色colorSplit
tailWidth轨迹宽度lineWidthBold
dotBorderWidth节点边框宽度lineWidthBold
itemPaddingBottom时间项下间距padding * 1.25
dotSize节点大小⚠️ undefined（刻意不声明，见下）
dotBg节点背景色⚠️ undefined（同上）

🚨 dotSize / dotBg 默认是 undefined、产物里也刻意不声明 —— 它们靠 var(custom, origin) 的两层回退链：未设置时回退到 Steps 的原生尺寸/背景色， 设置后才生效。这不是遗漏，是判据（补一条声明会让回退链失效）。

运行时调参用 CSS 变量：--apollo-timeline-tail-color / --apollo-timeline-dot-size 等。
