## zh-CN

组件内置文案（空状态、分页、确认弹窗等）通过 `@apollo-design/locale` 提供：

```vue
<script setup lang="ts">
import { LocaleProvider, zhCN, enUS } from '@apollo-design/locale';
import { ref } from 'vue';

const locale = ref(zhCN);
</script>

<template>
  <LocaleProvider :locale="locale">
    <RouterView />
  </LocaleProvider>
</template>
```

- 内置几十种语言包（`zh_CN` / `en_US` / `ja_JP` / …），命名与 antd 对齐。
- `useLocale()` 在任意组件内读取当前语言包。
- 切换 `locale` 引用即全局生效，无需重新挂载。

### 本文档站

站点自身的界面文案（导航、工具栏、搜索提示等）是独立的一套词典，右上角切换中 / 英；组件文档在中英两份内容间切换，缺失英文译文时**明确回退到中文并给出提示**，不静默混排。

## en-US

Built-in component texts are provided by `@apollo-design/locale`: wrap your app with `LocaleProvider` and a locale object (`zhCN` / `enUS` / dozens more, named like antd). Read the active locale anywhere via `useLocale()`. This site switches its own UI strings and component docs between zh-CN and en-US; missing translations fall back explicitly with a visible hint.
