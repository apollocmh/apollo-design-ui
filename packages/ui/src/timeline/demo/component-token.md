通过当前 ConfigProvider 的 `theme.components.Timeline` 动态覆盖六个组件 Token；切换后恢复默认大小、背景和间距。也支持根 `--apollo-timeline-*` CSS 变量。

Use current `theme.components.Timeline` to update all six component tokens. Toggle to restore the default node fallback, background and spacing. Root CSS variables are also supported.
