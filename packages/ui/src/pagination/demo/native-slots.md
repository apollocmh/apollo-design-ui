  en-US: Dynamic native slots

使用单个具名对象定义页码、总数和尺寸切换器。条件插槽可在挂载后出现或移除，空内容压住默认页码；根原生 attrs、事件和字符串样式按 Vue 规则更新。

<!-- en-US -->

Render pages, totals and size controls through named slot objects. Add or remove slots after mount; empty content suppresses default pages. Native root attrs, events and string styles update through Vue.
