## zh-CN

通过当前 ConfigProvider 修改十二个已有 Avatar Token。开关移除覆盖，溢出按钮可用鼠标或 Enter/Space 打开，观察隐藏头像间距。

## en-US

Change the twelve existing Avatar tokens through the current ConfigProvider. Toggle the override off to restore inherited values. Open overflow with a pointer or Enter/Space to inspect hidden avatar spacing.
