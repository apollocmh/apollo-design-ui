## zh-CN

使用原生 `#icon` 组合图标组件与当前内容。槽优先于 icon 数据，包括有意为空；移除槽后恢复默认图标或 icon 数据。静态预览传入 false，移除槽后隐藏图标；正文输入保持。

## en-US

Compose icon components and current content with the native icon slot. A present slot overrides icon data, including empty content. Removing it restores the default icon or data prop. The static preview uses false, so removing its slot hides the icon while preserving the body input.
