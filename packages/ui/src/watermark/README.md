# Watermark 实现说明

当前规范见 [AGENTS.md](../../../../AGENTS.md)，公开契约见 [API](./index.zh-CN.md)。早期分析与 s42/s49 保留原有来源及有效行为，不以旧的上游逐字对齐要求约束当前 Vue 实现。

- 根 `div` 承载默认槽、原生 attrs 与 `nativeElement`。Vue 合并默认、Provider、原生样式；防篡改恢复使用同一当前来源。
- `remove` 是 Vue owned 事件；不同时调用回调 prop。主动释放与继承搬运不触发通知。
- `getClips` 保留内容、旋转和交错平铺的既有几何。字体先由 canvas 原生规范化，再按既有像素比与行间距绘制；不实现 CSS 字号解析器。
- 最近一次绘图缓存使用真实文本/图片地址及几何参数。帧调度合并最新请求，配置变更立即作废旧图回调；正常卸载取消帧并释放图片处理器。
- `usePanelRef` 处理当前原生元素或真实 Vue 组件根，替换目标和选择器时先注销旧面板。稳定注入服务在 `inherit` 切换时搬运面板，不重挂槽子树。
- 每个宿主只有一个受管理装饰节点。观察器回写不重复设置相同样式；清理会移除实际位置上的节点并注销观察点，包括 Teleport 面板。
- SSR 仅输出根与槽；绘图只在挂载后启动。无 canvas 2D 上下文时跳过绘制。跨域图片仍需服务端允许 CORS，否则使用文本回退。

没有样式表或 Component Token；运行时读取当前 `zIndexPopupBase - 1`、`colorFill` 和 `fontSizeLG`。`demo/portal.vue` 使用实际 Modal 的注册链。外部字体加载、页面字号变化不另设观察平台，相对单位在下一次重绘时重新求值。
