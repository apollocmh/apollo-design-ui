## zh-CN

通过局部ConfigProvider覆盖全部7个Image Token；预览经Portal挂到body后仍消费源主题。打开单图或分组后，在工具栏切换自定义亮色、暗色紧凑和移除主题，观察图标字号、分组按钮尺寸、层级及进度动效时长。编辑器与当前预览保持；自定义样式仍可覆盖变量。

## en-US

Override all seven Image tokens through a local ConfigProvider. The body-mounted preview retains its source theme. Cycle custom light, compact dark and removed themes while open; icon size, group switch size, stacking and progress duration follow the current values while the preview and editor remain mounted.
