## zh-CN

多个图片放在 `Image.PreviewGroup` 中，可切换预览。

默认计数在主题背景上显示，遮罩关闭时也保持文字对比；背景取自 `colorBgSpotlight`。

## en-US

Put multiple images in `Image.PreviewGroup`.

The default counter uses the theme's `colorBgSpotlight` background to retain text contrast, including when the mask is disabled.
