在 `DatePicker` 根元素上覆写 `--apollo-date-picker-*` CSS 变量即可定制组件样式，例如 `--apollo-date-picker-active-border-color`、`--apollo-date-picker-hover-border-color`、`--apollo-date-picker-active-shadow`、`--apollo-date-picker-input-font-size`、`--apollo-date-picker-cell-hover-bg` 与 `--apollo-date-picker-presets-width`。打开面板可观察单元格悬浮色。
