## zh-CN

在抽屉中使用 Avatar 与 Descriptions 分组展示示例用户的基本资料和工作信息。面板适应可用宽度，可通过底部按钮或抽屉关闭按钮关闭，再次打开仍展示同一份静态资料。

## en-US

Display a sample user's personal and work details in a drawer with Avatar and Descriptions. The panel fits the available width and can be closed from its footer or header, then reopened with the same static profile.
