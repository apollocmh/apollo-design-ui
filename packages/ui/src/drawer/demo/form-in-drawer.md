## zh-CN

在抽屉中填写姓名与邮箱，通过底部操作区提交。必填和邮箱格式由 Form 校验；校验失败保留输入，成功后关闭并显示本地提交结果。取消或关闭后重新打开，会清空草稿与校验信息。

## en-US

A contact form inside a drawer, with required-name and email validation and submit actions in the footer. Invalid input stays open; a valid submission closes the drawer and displays local feedback. Reopening starts a clean form. This example does not send a network request.
