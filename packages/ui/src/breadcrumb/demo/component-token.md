通过根元素的 `--apollo-breadcrumb-*` 组件 Token 变量自定义链接颜色、悬浮颜色、末项颜色与分隔符间距。颜色引用当前主题的语义变量，随暗色与紧凑主题更新。

Override the root `--apollo-breadcrumb-*` variables to customize links, hover, the current item and separator spacing. Semantic color variables follow the current light, dark and compact theme.
