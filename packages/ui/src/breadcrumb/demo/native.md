  en-US: Native composition and current content slots

原生 attrs 落所属 Item 的 li；导航与菜单按钮独立。使用条件插槽更换图标/分隔符，通过 dropdownProps.open/onOpenChange 控制菜单。

Native attrs belong to the Item li. Navigation and menu buttons are independent. Conditional slots change icons/separators; dropdownProps.open/onOpenChange controls the menu.
