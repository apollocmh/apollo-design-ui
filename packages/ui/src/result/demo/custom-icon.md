## zh-CN

普通和异常状态均优先使用完整的 `#icon` 插槽。切换状态保留编辑器，选择有意留空时不回退图标；移除插槽才恢复默认图形。

## en-US

The complete `#icon` slot overrides the default graphic for every status. Status changes preserve the editor. An empty slot suppresses the fallback; removing the slot restores it.
