## zh-CN

通过局部 ConfigProvider 切换已有 `titleMarginTop` / `titleMarginBottom` 的默认、自定义与零值。上间距作用于排版内容后的标题，首个标题不额外增加上间距。别名示例保留：标题宿主用原生 CSS 变量覆盖字号与字重，正文和次要文字继续读取当前主题。

## en-US

Cycle the two existing title-spacing tokens through defaults, custom values and zero. Top spacing applies to headings following typography content. The native heading variables demonstrate font size and weight; body and secondary text retain the current theme.
