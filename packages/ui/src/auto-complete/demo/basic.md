## zh-CN

不自定义过滤条件（`showSearch.onSearch` 驱动候选）+ 受控模式。

第二个输入使用三个模型；开启 `backfill` 后，键盘导航只预览候选，Enter/Tab 或点击确认时提交值。

## en-US

Basic usage with controlled mode.

The second input binds all three models. With `backfill`, keyboard navigation previews a candidate; Enter/Tab or a click commits the value.
