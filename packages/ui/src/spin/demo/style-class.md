## zh-CN

root、section、indicator、description、container、mask均作用于各自实际容器；tip是既有文案别名。对象和函数式配置读取当前值，局部样式优先于Provider。

## en-US

Root, section, indicator, description, container and mask target their actual hosts; tip is the existing description alias. Object/factory settings consume current values, with local styles taking precedence over Provider.
