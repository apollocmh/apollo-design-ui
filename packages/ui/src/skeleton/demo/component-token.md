六种骨架形态共享当前源主题。切换主题、动画或原生标题高度变量，输入值与焦点保持；内容样式使用`styles.content`，普通`style`作用于根。

All six shapes follow the current source theme. Theme and native-variable changes preserve the editor; `styles.content` targets the inner content and native `style` targets the root.
