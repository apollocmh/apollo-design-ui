## zh-CN

异步加载候选项，使用原生 `#notFoundContent` 模板显示当前搜索词。更新模板内容、令插槽有意为空，或移除插槽恢复当前 `notFoundContent` 数据；操作按钮保持编辑器焦点。匹配后可正常选择和清空。

## en-US

Load candidates asynchronously and show the current query with the native `#notFoundContent` template. Update its content, leave the slot intentionally empty, or remove it to restore the current `notFoundContent` data. The controls preserve editor focus; matching candidates still support selection and clear.
