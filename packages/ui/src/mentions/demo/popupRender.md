## zh-CN

使用原生 `#popupRender="{ originNode }"` 包装默认菜单。输入 @ 后可切换、更新或清空槽；空槽不恢复菜单，移除槽才恢复。工具栏鼠标操作保留编辑焦点，默认菜单的键盘导航与选择继续工作。

## en-US

Wrap the default menu with the native popupRender slot and its single originNode context. After typing @, toggle, update or empty the slot. Empty content suppresses the menu; removing the slot restores it. Mouse toolbar actions preserve editor focus, and the original menu retains keyboard navigation and selection.
