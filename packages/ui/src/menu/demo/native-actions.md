## zh-CN

方向键移动菜单焦点，Enter 激活所属原生链接或按钮。直接聚焦子控件时保留浏览器自己的激活语义；普通菜单项也支持 Space。按钮每次仅执行一次，禁用链接不会导航。

## en-US

Arrow keys move menu focus. Enter on an item activates its single native link or button. Focused child controls retain browser activation; plain items also support Space. Actions run once and disabled links do not navigate.
