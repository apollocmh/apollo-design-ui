title: 组件 Token
title.en-US: Component tokens
---

切换当前 Menu 组件 Token，菜单保持当前选中状态。公开 Token 与全局 Alias 同步投影到根列表和弹出子菜单；静态 CSS 变量继续支持样式定制。

Switch the current Menu component tokens while preserving selection. Public tokens and current global aliases reach both the root list and teleported submenus; static CSS variables remain available for styling.
