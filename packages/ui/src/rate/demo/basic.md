## zh-CN

聚焦评分后用左右方向键更新分数。`@keydown` 注册原生键盘监听器，每次按键调用一次，和 `v-model:value` 同时工作；禁用时不处理评分键盘事件。

## en-US

Focus the rating and use the arrow keys to update its value. `@keydown` receives each native keyboard event once alongside `v-model:value`. Disabled ratings suppress keyboard handling.
