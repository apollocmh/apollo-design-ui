## 发现 antd 缺陷，登记为 D13

`getIntersectionArea`：antd 用 `Math.max(0, w*h)`，浮层整体在区域外侧时两差值同负、
乘积为正 → "完全不可见"被算成 17,600,000 的正面积，翻转判定会接受更差的位置。
改为逐轴夹取。**oracle 上留 `clampIntersection` 开关**，使"这是唯一差异"成为断言：
不开夹取分歧 > 0、开夹取分歧 = 0（可证伪，antd 修了会变红）。

### 关键教训

- **PENDING ≠ 通过，n/a ≠ 掩盖**。一刀切把所有包的 B5-B8 标 PENDING 会让 `utils` 永远卡住 L7；
  一刀切标 n/a 又等于掩盖未做。判据必须是架构事实（产不产 CSS、含不含组件）。
- **必须从仓库根跑 vitest**。在 `packages/<x>/` 下跑不会应用根 config 的 jsdom 环境，
  utils 会假失败 160 个（"jsdom 下为 true" 这类断言全挂）。
- `pnpm install` / `pnpm -r build` 在本环境挂起（疑似网络），改用 `node_modules/.bin/unbuild` 逐包跑。
