### ⭐ 本轮最有价值的发现：生成物豁免必须在**采集层**实现

`ARCHITECTURE.md` §7 写「`icons` 与 `locale` 是生成物，豁免覆盖率要求」，
`vitest.config.ts` 的 `coverage.thresholds` 也确实没列 icons —— **但这不够**。

`coverage.all` 默认为 `true`，849 个生成模块照样被插桩并写进 `coverage-summary.json`；
而 `foundation-status.mjs --verify` 的 `coverageFor(dir)` 是按
`packages/icons/src/` **前缀聚合**的，于是生成文件被算进 icons 的覆盖率：

| 采集范围 | statements | branches | functions | `met` |
|---|---|---|---|---|
| 含 849 个生成模块 | 99.5 | 95.93 | **91.18** | ❌ false |
| 仅 9 个手写文件 | **100** | **100** | **100** | ✅ true |

后果是**文档说豁免、工具说不达标**，且谁都无法靠补测试解决（给生成文件写测试毫无意义）。

修法：`vitest.config.ts` 的 `coverage.exclude` 加 `packages/icons/src/icons/**`。
**9 个手写文件一个都不豁免**，仍按 95/90/95 —— 这是**收紧而非放宽**（H8）。
顺带把覆盖率内存占用降到可跑：此前 `--coverage` 反复被 SIGKILL（exit 137），
不带 `--coverage` 时 icons 的 95 个用例稳定通过。

> 教训：**「不在阈值档位里」≠「不参与采集」**。凡声明豁免，必须同时确认采集层也排除了。

### ⭐ 第二有价值的发现：`--verify` 的并发静默数据损坏（已修）

`runVerify()` 原先没传串行标志。vitest 5 并发跑多 project 时 worker 互相干扰：
`--reporter=json --outputFile` 只捕获到 **7 个测试文件 / 125 个用例**（实际 35 / 950），
覆盖率只采集到 43 个文件（theme / icons 是 0 个），于是**把 utils 的 98% 写成 10.37%、
`met` 从 true 变 false** —— 一次 `--verify` 就把另一个包的达标记录改坏了，且完全静默。

修法：`runVerify()` 加 `--maxWorkers=1 --no-file-parallelism`。
修复后 utils 精确恢复原值（98 / 94.15 / 96.17，`met=true`）。
**改这个工具前先 `git show HEAD:registry/foundation.json > /tmp/x.json` 备份**，否则无从对照。

另：`TEST_PROJECTS` 原先漏了 `a11y`（因为第一个有 a11y 测试的包才刚出现）。

### 其他坑（实测）

- **axe-core 在 jsdom 下耗时对节点数二次方增长**：100→672ms、200→2057ms、400→11941ms、
  848→被杀。一次挂 848 个图标扫描直接 exit 137。解法是**分块扫描**（每块 100），
  总耗时 ~6s，且**仍是全量覆盖**不是抽样。另加一条「扫描有牙」的元测试：
  手写一段只差 `aria-label` 的 DOM，断言 axe 必报 `role-img-alt(1)` —— 防扫描恒过。
- **`*.test-d.ts` 会被 vitest 真的执行一遍**（types project 只是额外叠了 tsc 检查）。
  负例 `setTwoToneColor(123)` 真的跑起来会抛
  `TypeError: Cannot use 'in' operator to search for 'r' in 123`。
  **负例必须只声明不调用**：`const bad = () => setTwoToneColor(123); void bad;`
- **`props.children`（React）与 `slots`（Vue）不可移植**。给 oracle 加 `data-children` 标记
  会被 Vue 侧无脑判为差异（Vue 组件没有 `props.children`），是**假差异**。已否决该方案。
- **Vue 渲染 `null` 的产出是注释占位符 `<!---->` 而不是空串** —— 断言写 `toBe('')` 会红。
- **`createIcon` 与基础 `Icon` 各自复制了一份 `tabIndex` 兜底逻辑**（与 antd 的
  `AntdIcon` / `IconBase` 分工一致）。测了前者**走不到后者** —— 这类「同一规则两处实现」
  必须分别钉住，否则覆盖率会诚实地暴露它（`icon.ts:108-111` 当时是未覆盖的）。
- **`noUncheckedIndexedAccess` + namespace import**：`Icons.HomeOutlined` 保留具体组件类型，
  而 `Icons as unknown as Record<string, Component>` 索引出来是 `Component | undefined`，
  会让 `h()` 重载解析失败（曾一次报 40 个 unhandled TypeCheckError）。用具名访问。
- **`pnpm -r build` / 全量 `tests/build/run.mjs` 在本机会被 SIGKILL**（13 个包串行 unbuild）。
  按包跑（`--package icons`）正常。已实测 icons 单独构建通过。
- 预存在（非本轮引入，已 `git status` 确认文件未改动）：
  - `packages/theme/build.config.ts(21,32)` TS2307 —— 因为 `dist/` 未构建（`dist` 不入库），
