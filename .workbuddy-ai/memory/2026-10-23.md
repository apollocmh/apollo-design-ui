## 交付：GitHub Pages 部署架构简化（移除 gh-pages 分支依赖）

### 背景 / 根因

- 原架构：Pages `build_type=legacy`，发布源 `gh-pages`；workflow 构建后 checkout `gh-pages` → 替换内容 → push。
- 2026-10-21 `actions/deploy-pages` 被拒的根因不是权限声明，而是 `github-pages` Environment
  的 deployment branch policy **只允许 `gh-pages`**；`deploy-pages` 的部署 ref 是触发 ref。
- 用户 2026-10-23 裁决：只保留 `master` 长期分支；改用官方 Actions Pages；产物不落任何 Git 分支；
  保留 `v*` 标签 + 手动触发的发布规则与 `/apollo-design-ui/` 子路径。
