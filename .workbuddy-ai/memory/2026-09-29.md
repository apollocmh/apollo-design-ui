`.apollo-slider`）；已注册进 `COMPONENT_STYLES` + 组件/根 barrel 导出。

**冒烟证据**（写完即验，验完删临时用例）：默认（`aria-valuenow=30` + track `width:30%`）/
range（2 把手）/ vertical（类名 + `aria-orientation`）/ marks（2 个 `-mark-text` + 2 个 dot）/
**键盘 ArrowRight → `change: [31]`** 全通过；无「Extraneous non-emits event listeners」告警。

**G4 期间踩/记的坑**（值得复用）：
1. `useMergeSemantic` 返回**对象** `{classNames, styles}`（不是元组）—— 元组解构会得到
   `undefined`，症状是 `object is not iterable` 或类名全丢。
2. `useControlledValue` 是**选项对象**签名（`{defaultValue, getValue, onChange}`），不是位置参数。
3. `useOrientation` 返回 `ComputedRef<[Orientation, boolean]>` —— 取垂直要 `.value[1]`。
4. `devUseWarning` 的 warn 是**两参** `(valid, message)`（antd 是三参，多了个 code）。
5. 子组件用**自定义事件名**传 handler（`onMouseEnterChange` 之类）时，父级若把 antd 风格名
   （`onBlur`）直接透传给未声明的子组件，Vue 会告「Extraneous non-emits event listeners」
   —— 必须用子组件声明过的 prop 名。
6. `noUncheckedIndexedAccess` 下 rc 风格的 `arr[i]` 大量报错：本仓手法是加 `readAt(arr, i, fallback)`
   显式化（**不用 `!`**，那会触发 `noNonNullAssertion`），fallback 取 min/max 并在注释里写明不可达。
7. jsdom 的 `KeyboardEvent` 的 `which` 是只读 getter ⇒ 测键盘要
   `new KeyboardEvent('keydown',{keyCode}) + Object.defineProperty(ev,'which',{value})`，
   VTU 的 `trigger('keydown',{which})` 会直接抛错。
8. `extract-*-css.mjs` 的 `--emit-static` 必须放在「打印原始产物」那个出口**之前**（否则被吞）。
