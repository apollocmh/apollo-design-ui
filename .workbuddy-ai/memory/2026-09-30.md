   ⇒ 新组件的通则：**回调要么是 prop、要么是 emit，不能两边都声明同名 camelCase**。
3. **`menu` 的两处缺口**（已完成组件）：①`MenuItem.ts` 渲染期遗留

   ②rc-menu 的 `role` 可被 restProps 覆盖（`role` 写在 `_extends({...}, restProps)` **之前**），

### 工具链经验
- **`.mjs` 脚本不能写 JSX**（`extract-tabs-css.mjs` 一开始写了 `<span>`，直接 `SyntaxError`）
  ⇒ 用 `React.createElement`。
- **`h(Component, props)` 的 TS2769 是常态**：本仓手法是 `h(Comp as never, {...} as never)`；
  `h('span', null, [...])` 里的 `null` props 在 children 含 `null`/`undefined` 时也会报
  ⇒ 改 `{}` + 子节点 `as never`。
- `InstanceType<typeof Comp>` **拿不到被 `expose` 的方法** ⇒ 用
  `type MeasurableInstance = { getElement: () => HTMLElement | null } | null`。

  ⇒ popup 的展平要手工做（并在 computed 返回值上按公开类型断言）。
