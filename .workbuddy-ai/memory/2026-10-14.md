### 本轮最有价值的四条（已进 MEMORY §6）

1. 🚨 **末尾 `...restAttrs` 会覆盖内部同名事件键**（对象展开后者胜）。cascader 把
   BaseSelect 的 `onSearch` / `onOpenChange` 顶掉（内部 `setSearchValue` / `setOpen` 不再跑）；
   switch 的 `onKeydown` 被内部覆盖（模板 `@keydown` 一次都不调）。
   ⇒ **内部持有的事件键必须先从 `restAttrs` 摘掉**。
2. 🚨 **「注释写着正确规则、代码没照做」这类缺口真实存在**（switch #11.2 的
   `interface.ts` 注释、radio README 的 D44「form 未落地」）。⇒ 判据要**跑代码**验证。
3. 🚨 **prop 默认值写成字面量会堵死 ConfigProvider 回退**：
   `direction: { default: 'ltr' }` ⇒ `props.direction ?? ctx ?? 'ltr'` 永远短路在第一支。
   收敛成 `default: undefined` + `mergedDirection`。
4. 🚨 **上游 `useXxx(...)` 在 React 是每次渲染重算 ⇒ Vue 侧必须包 `computed`**，
   否则动态改 `showSearch` / `filter` / `sort` / `limit` 全部无效（cascader #12.3）。

### 一条误报（#10.3 `skipGroup`）

⇒ 保留声明（类型面对齐 + 从 attrs 摘掉以免多出 `skipgroup` 属性），**不给运行时语义**。

### 三件修复（都先复现失败路径）

1. **VNode dataSource 全丢**：`mergedOptions` 对 VNode 数据源返回 `[]` ⇒
   `options=[]` 显式传 Select ⇒ `childrenAsData = ![] = false` ⇒ 插槽里的 VNode

   （结构化项渲染期 `h(SelectOption)` 转 vnode）。
2. **size 缺 medium**：手写三档 → 共享 `SizeType`。
3. **动态 slot 分类过期**：修复前实测「自定义输入结构切回 Option 列表后候选不恢复」。

### 两个新判别式（已进 MEMORY.md）

- 🚨 **computed 调 `slots.default?.()` 不过「插槽引用/有无」的变化** —— Select 的
  `parsed` 实测：挂载时无 default slot ⇒ 求值什么都不 track ⇒ 之后 slot 从无到有，
  Select 重渲染了但 computed 缓存干净 ⇒ 选项永远不出现。**引擎级缺口**（影响
  Select/TreeSelect/Cascader 用户侧条件插槽，已登记 KNOWN-ISSUES §1.4，两条候选修法）。
  AutoComplete 侧绕法：默认插槽**始终下传** + 包装函数显式读分类态 ⇒ `parsed`
  间接跟踪。判别式：**给子组件的插槽内容函数要读本组件的 reactive 分类态**，
  别当纯透传。
- 🚨 **computed 里的 dev 告警副作用会随「惰性求值不被触发」一起消失**：仅传
  `options` 时 `mergedOptions` 首行短路 + `childrenAsData=false` ⇒ `optionInfo`
  永不求值 ⇒ 「Custom input element」告警消失（本轮回归实测）。⇒ 告警移渲染期
  沿对比触发。

### 排查方法留痕

插桩法定位 computed 缓存问题：在 computed 求值函数体 / 渲染函数里打日志，看
「组件重渲染了但 computed 没重新求值」⇒ 直接锁定缓存干净。本轮据此在 5 分钟内
区分了「AutoComplete 分类错」与「Select parsed 缓存旧」两种假设。
