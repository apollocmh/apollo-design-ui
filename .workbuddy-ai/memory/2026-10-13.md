## 复用到的判别式（下次直接抄）

- **`useAttrs()` 不参与依赖追踪** ⇒ 包进 `computed` 就是首帧快照。全仓已修：Button / Space×3 / Select / DatePicker / RangePicker。判据：**模板里 `v-bind="fn()"`**（渲染期求值），且 `vue-tsc` 要求 `fn()` 的第一个实参满足组件必填 prop ⇒ 模板里把必填 prop 显式写出来。
- **公共 Hook 收裸值 = 静默失效**：`useAllowClear` / `useMergeSemantic` / `useDisabled` 都改成 `MaybeRefOrGetter` + `toValue`。
- **语义 `root` 槽要真的落根**：date-picker 的 `classNames.root` / `styles.root` 此前**从未落到任何元素**。落点规律见 rc `SinglePicker.js:476-478`：class = `[rootClass, classNames.root]`、style = `[styles.root, rootStyle]`（数组，**不能对象展开** —— `attrs.style` 可能是字符串）。
- **Vue 组件 expose 用 getter**：`defineExpose({ get nativeElement() {…} })`，`proxyRefs` 每次访问现算。

## 新踩的坑（全文进 KNOWN-ISSUES / 提交信息）

1. 🚨 **SFC 模板里放 HTML 注释会顶掉 `Trigger` 的触发元素** —— Vue 把模板注释编译成 Comment vnode，而 `_internal/trigger.ts:613-614` 取的是 `slots.default()[0]`。症状：整组件渲染成空（`w.find('.apollo-picker')` 恒 false）。**注释要写在 `<script>` 里。**
2. 🚨 **`{...attrs.style}` 会炸** —— `style` 可能是字符串，展开成 `{0:'w',1:'i'…}` ⇒ Vue `setStyle` 抛 `'set' on proxy: trap returned falsish`。用样式数组。
3. ⚠️ **jsdom 里纯 `picker: 'time'` 的面板渲染为空**（`-content` 零列），`datetime` 正常、L6（真浏览器）正常 ⇒ 列数类断言在 jsdom 不可用。**这是 #6.2/#6.5 未交付的直接原因**（见 KNOWN-ISSUES §1.4）。
4. ⚠️ **`w.emitted('x')` 对「薄壳不声明 `defineEmits`」的组件无效**（time-picker 就是）—— 要 spy 转发下去的 `onXxx`。
5. ⚠️ **`known-issues` 的坐标要复核**：`docs/KNOWN-ISSUES.md` §1.8 里「`id` 不被 attrs 顶掉」是**空转断言**（`id` 整条链路丢失，见 §1.3）。
